How to view exact order details (UI + DB)

Prereqs
- Supabase: set NEXT_PUBLIC_SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY in .env
- Optional Shopify sync: set SHOPIFY_STORE_DOMAIN and SHOPIFY_STOREFRONT_ACCESS_TOKEN

One‑time DB setup (run in Supabase SQL editor)
1) Run supabase/checkout-update.sql
   - Adds discount columns (if missing)
   - Backfills old zero totals to subtotal+tax
   - Marks discounted orders as paid
2) Run supabase/checkout-update-v2.sql
   - Backfills order_items for orders in the last 24h that have none
   - Uses SKUs: BOT-004 (bottle), CAP-001 (cap), BUL-002 (RedBull), PEN-003 (pen), SUN-005 (socks)
3) Run supabase/products-upsert-skus.sql
   - Upserts canonical product rows with those SKUs so reporting stays consistent

Start the app
- pnpm dev

See the exact order details in the UI
- Open the Sales page: http://localhost:3000/sales?mode=client
- All transactions appear; click “View Details” on a row to see every line item (SKU, qty, price)
- Notes:
  - Checkout records every cart item into public.order_items with sku/qty/price
  - Orders are stored with pre‑discount totals; discounts tracked separately (discount_cents/discount_label)

Optional: Sync products from Shopify (ensures SKUs/names/prices are in Supabase)
- All products:  curl -X POST http://localhost:3000/api/sync-products
- One product:  curl -X POST "http://localhost:3000/api/sync-products?handle=<shopify-handle>"

Check the raw data in Supabase (SQL examples)
- Latest orders with items (basic):
  SELECT o.order_id, o.created_at, o.subtotal_cents, o.tax_cents, o.total_cents,
         o.discount_cents, o.status,
         oi.sku, oi.qty, oi.price_cents
  FROM public.orders o
  JOIN public.order_items oi ON oi.order_id = o.order_id
  ORDER BY o.created_at DESC, oi.created_at ASC;

- With product names if you’ve synced products and aligned SKUs:
  SELECT o.order_id, o.created_at,
         p.name AS product_name, oi.sku, oi.qty, oi.price_cents,
         o.subtotal_cents, o.tax_cents,
         (o.total_cents - o.discount_cents) AS net_total_cents
  FROM public.orders o
  JOIN public.order_items oi ON oi.order_id = o.order_id
  LEFT JOIN public.products p ON p.sku = oi.sku
  ORDER BY o.created_at DESC, oi.created_at ASC;

Troubleshooting
- No line items for old orders: run checkout-update-v2.sql again (it only fills the last 24h for orders with zero items)
- SKUs don’t match: run products-upsert-skus.sql to align Supabase products with canonical SKUs
- Missing product rows: POST /api/sync-products to import from Shopify

Tip
- The navbar uses a simple mode switch: add ?mode=client to URLs to expose merchant pages/links during demos.
